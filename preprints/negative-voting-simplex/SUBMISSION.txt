UPLOAD
Use archives/negative-voting-simplex-arxiv-source-2026-11-02.tar.gz from the
repository root or the immutable GitHub release. It contains the LaTeX inputs,
references, analytic proof companions in anc/, and partial Lean source in
anc/lean/. It excludes the generated manuscript PDF, build caches, installed
dependencies, and third-party papers. The PDF is a separate review artifact.

In an authenticated arXiv author account, start a new submission and select
an appropriate category and license. The license is deliberately not selected
in submission.json. Upload the source archive, select main.tex and pdfLaTeX,
then inspect arXiv's compiled PDF. Supply the title, author information and
abstract matching the manuscript. An endorsement may be required by arXiv;
moderation and acceptance are outside this package.

FORMAL VERIFICATION BOUNDARY
The Lean project proves selected algebra, finite routing, general
measure-theoretic routing rigidity, and conditional comparison assembly.
Its hypotheses include the analytic inequalities supplied by the manuscript.
Neither its compilation nor GitHub CI certifies the full Gaussian theorem.
